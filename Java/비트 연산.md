# 비트 연산(Bitwise Operations)

## 마스크(Mask)

**마스크**는 비트 연산에서 특정 비트만 선택하거나 조작하기 위해 사용하는 값이다.

`1 << n`은 n번 비트만 1인 마스크를 생성한다.

```java
1 << 4 // 0001 0000
```

## 특정 비트 조작

- n번 비트 설정(1): `reg |= (1 << n)`
- n번 비트 해제(0): `reg &= ~(1 << n)`
- n번 비트 반전: `reg ^= (1 << n)`
- n번 비트 확인: `if ((reg & (1 << n)) != 0) { /* n번 비트가 1 */ }`

## 연속된 비트 마스크 생성

`(1 << n) - 1`은 하위 n개 비트가 모두 1인 마스크를 생성한다.

```java
1 << 4  // 0001 0000
        // 0001 0000 - 1
        // 0000 1111
```

## 특정 비트 범위 추출
`(reg >> n) & ((1 << (m - n + 1)) - 1)`은 n번부터 m번 비트까지 추출한다.

- `reg >> n`: 오른쪽으로 n칸 밀어서, 원하는 구간의 시작 비트(n번)가 0번 자리에 오게 한다.
- `(1 << (m - n + 1)) - 1`: 구간 길이 m - n + 1개만큼 하위 비트가 1인 마스크를 만든다.
- `&`: 마스크와 AND해서 구간 위쪽 비트를 모두 0으로 지운다.

```java
int reg = 0b1101_0110;

int extracted = (reg >> 4) & ((1 << 3) - 1);

// reg >> 4
// 0000 1101

// 마스크
// 0000 0111

// AND
// 0000 0101
```
