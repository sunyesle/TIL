# 메모리 매핑 파일(Memory-Mapped File)
**메모리 매핑 파일**은 파일의 전체 또는 일부를 프로세스의 가상 주소 공간에 매핑하여, 파일 I/O를 일반적인 메모리 접근처럼 처리하는 기법이다.

## 원리
1. OS가 파일의 전체 또는 일부를 프로세스의 가상 주소 공간에 매핑한다.
2. 프로세스는 `read()`/`write()` 시스템 콜 대신 일반적인 메모리 접근 명령어를 사용하여 파일의 데이터를 읽거나 수정한다.
3. 해당 주소에 접근했을 때 필요한 데이터가 메모리에 없으면 페이지 부재(Page Fault)가 발생하고, OS가 파일에서 해당 데이터를 메모리로 가져온다.
4. 프로세스가 데이터를 수정하면 해당 메모리 영역이 변경되며, OS는 적절한 시점에 변경된 내용을 파일에 반영한다.

## 장단점
- **장점**
   - `read()`/`write()` 시스템 콜 오버헤드와 사용자 공간과 커널 공간 사이의 불필요한 데이터 복사를 줄일 수 있다.
   - 필요한 부분만 페이지 단위로 메모리에 가져올 수 있어 대용량 파일을 효율적으로 처리할 수 있다.
   - 파일을 일반적인 메모리 접근 방식으로 처리할 수 있어 파일 I/O가 단순해진다.
   - 여러 프로세스가 동일한 파일 영역을 매핑하여 데이터를 공유할 수 있다.
- **단점**
   - 필요한 페이지가 메모리에 없으면 페이지 폴트가 발생하며, 페이지 폴트가 빈번한 경우 일반적인 파일 I/O보다 성능이 떨어질 수 있다.

## 활용
- 대용량 파일 처리
- 데이터베이스 및 파일 기반 데이터 처리
- 여러 프로세스 간 데이터 공유(IPC)
- 그래픽 카드처럼 대량의 데이터를 빠르게 이동해야 하는 장치
