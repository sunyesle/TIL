# 메모리 매핑 파일(Memory-Mapped File)
**메모리 매핑 파일**은 파일의 내용을 프로세스의 가상 주소 공간에 매핑하여, 메모리에 접근하듯 파일의 데이터를 읽고 쓸 수 있도록 하는 기술이다.

<img width="643" height="521" alt="9_23_MemoryMappedFiles" src="https://github.com/user-attachments/assets/61418566-b140-4292-a9a0-bc3f95198c85" />

## 장단점
- **장점**
   - `read()`/`write()` 방식에서 반복적으로 발생하는 시스템 호출 비용을 줄일 수 있다.
   - 여러 프로세스가 동일한 파일 영역을 매핑하여 데이터를 공유할 수 있다.
- **단점**
  - 필요한 페이지가 메모리에 없으면 페이지 폴트가 발생하며, 페이지 폴트가 빈번한 경우 일반적인 파일 I/O보다 성능이 떨어질 수 있다.
