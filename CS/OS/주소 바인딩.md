# 주소 바인딩

## 주소의 종류
### 심볼릭 주소(Symbolic Address)
프로그래머가 코드를 작성할 때 사용하는 변수명이나 함수명 형태의 주소이다.

### 논리적 주소(Logical Address, Virtual Address)
CPU가 바라보는 주소이자, 실행 중인 프로세스마다 독립적으로 부여되는 가상 주소이다.
각 프로세스는 0번지부터 시작하는 독립적인 주소 공간을 갖는다.

### 물리적 주소(Physical Address)
실제 메모리에서 데이터가 저장된 위치를 가리키는 주소이다.

## 주소 바인딩
주소 바인딩은 프로그램의 논리적 주소를 실제 메모리상의 물리적 주소로 연결하는 과정이다.
주소가 결정되는 시점에 따라 다음과 같이 구분된다.

### 컴파일 타임 바인딩
컴파일할 때 물리적 메모리 주소가 결정되는 방식이다.

- 메모리 주소가 고정된 절대 코드를 생성하며, 프로그램이 적재될 메모리 위치를 미리 알고 있어야 한다.
- 메모리 내 위치를 변경하려면 코드를 다시 컴파일해야 한다.

### 로드 타임 바인딩
프로그램이 시작되고 메모리에 적재될 때 물리적 메모리의 주소가 결정되는 방식이다.

- 로더(Loader)에 재배치 가능한(Relocatable) 주소가 절대(Absolute) 주소로 변환된다.
- 메모리에 적재될 때 주소 변환이 이루어지며, 프로그램이 종료될 때까지 메모리 내 위치가 고정된다.

### 런타임 바인딩
프로그램 실행 중에 논리적 주소를 물리적 주소로 변환하는 방식이다.

- 프로그램이 실행 중에도 메모리 내 위치를 변경할 수 있다.
- 메모리 접근마다 주소를 변환해야 하므로 **MMU**(Memory Management Unit, 메모리 관리 장치)라는 하드웨어의 도움을 받는다.
- MMU는 CPU가 생성한 논리적 주소를 물리적 주소로 변환한다.
