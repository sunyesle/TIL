# 커널 입출력 서브시스템
커널 입출력 서브시스템은 운영체제 커널 내부에서 입출력 요청을 관리하고 하드웨어 장치와 상호 작용하는 핵심 구성 요소이다.

## 입출력 스케줄링
여러 입출력 요청의 처리 순서를 결정하여 장치의 성능을 높이고 입출력 요청의 처리 효율을 향상시키는 기능이다.

## 버퍼링(Buffering)
**버퍼링**은 데이터의 입출력 과정에서 데이터를 임시로 저장할 버퍼를 사용하여 서로 다른 장치나 프로그램 간의 데이터 처리 차이를 조정하는 기법이다.

주요 목적은 다음과 같다.
- 장치 간 속도 차이 완화
- 데이터 전송 단위 차이 조정

버퍼링을 통해 데이터를 모아서 처리함으로써 입출력 작업 횟수와 처리 오버헤드를 줄일 수 있다.

## 캐싱(Caching)
**캐싱**은 자주 사용되는 데이터의 사본을 메모리 등의 빠른 저장 영역에 보관하여 데이터 접근 시간을 줄이는 기법이다.

캐싱은 버퍼링과 매우 유사하지만, 버퍼는 서로 다른 처리 속도/단위 사이에서 데이터를 임시로 중계하는 데 초점이 있고, 캐시는 같은 데이터를 다시 사용할 때 빠르게 제공하는 데 초점이 있다.

## 스풀링 및 장치 예약
### 스풀링(Spooling)
**스풀링**은 입출력 데이터를 디스크의 임시 저장공간에 대기 시키고, 장치가 처리할 수 있을 때 순서대로 처리하는 기법이다.

느리거나 한 번에 하나의 작업만 처리할 수 있는 입출력 장치(ex. 프린터)를 여러 프로세스가 공유할 수 있도록 한다.

### 장치 예약(Device Reservation)
**장치 예약**은 특정 프로세스가 하나의 입출력 장치를 독점적으로 사용할 수 있도록 제어하는 기법이다.

다른 프로세스가 해당 장치를 사용하려고 하면 장치를 사용할 수 있을 때까지 기다리도록 하여 동시에 접근하는 것을 방지한다.
