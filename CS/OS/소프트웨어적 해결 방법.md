# 소프트웨어적 해결 방법

## 데커의 알고리즘
두 개의 프로세스 간 상호 배제를 보장하는 최초의 알고리즘이다.

```c
boolean flag[2]; // 들어가고 싶은지 여부
int turn; // 누구 차례인지

do {
    flag[i] = true;
    
    while (flag[j]) {
        if (turn == j) {
            flag[i] = false;

            while (turn == (j)); // 상대 차례가 끝날 때까지 대기
            
            flag[i] = true;
        }
    }
    
    // 임계 영역
    
    turn = j;
    flag[i] = false;
    
    // 나머지 영역

} while (true);
```

## 피터슨의 알고리즘
데커 알고리즘을 단순화한 버전이다.
```c
boolean flag[2]; // 들어가고 싶은지 여부
int turn; // 누구 차례인지

do {
    flag[i] = true;
    turn = j; // turn을 미리 양보한다
    
    while (flag[j] && turn == j); // 상대 차례가 끝날 때까지 대기
    
    // 임계 영역
    
    flag[i] = false;
    
    // 나머지 영역

} while (true);
```

## 베이커리 알고리즘
여러 개의 프로세스 간 상호 배제를 보장하는 알고리즘이다.

```c
boolean choosing[N] // 번호 뽑는 중인지
int number[N] // 티켓 번호

do {
    choosing[i] = true;

    number[i] = max(number[0], ..., number[N-1]) + 1; // 대기 중인 프로세스 중 가장 높은 번호보다 1 큰 값을 할당

    choosing[i] = false;

    for (j = 0; j < N; j++) {
        while (choosing[j]); // 번호 뽑는 중이면 대기

        while (number[j] != 0 &&
              (number[j] < number[i] || (number[j] == number[i] && j < i)));
    }

    // 임계 영역

    number[i] = 0;

    // 나머지 영역

} while (true);
```
