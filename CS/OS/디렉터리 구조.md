# 디렉터리 구조
## 1단계 디렉터리(Single-Level Directory)
파일 시스템 전체에서 하나의 디렉터리만 사용하는 구조이다.

- 구현이 단순하다.
- 모든 파일 이름이 유일해야 하므로 파일 수가 늘어나면 이름 충돌이 발생하기 쉽다.

## 2단계 디렉터리(Two-Level Directory)
마스터 파일 디렉터리(MFD)와 사용자 파일 디렉터리(UFD)로 분리하는 구조이다.

- 각 사용자 UFD 내에서만 이름이 유일하면 되므로 이름 충돌 문제가 해결된다.
- 사용자 간 파일 공유가 어렵다.

## 트리 구조 디렉터리(Tree-Structured Directory)
계층적인 트리 형태 구조이다.

- 계층적으로 파일을 분류할 수 있어 파일 관리가 용이하다.
- 파일이나 디렉터리에 접근할 때 절대 경로 또는 상대 경로를 사용할 수 있다.
- 기본적으로 각 파일은 하나의 디렉터리 계층에 속하며, 디렉터리 간 직접적인 공유를 지원하지 않는다.

## 비순환 그래프 디렉터리(Acyclic-Graph Directory)
트리 구조를 기반으로 하되, 링크를 추가하여 파일이나 디렉터리의 공유를 허용하면서 순환은 허용하지 않는 구조이다.

- 링크를 통해 하나의 파일이나 디렉터리를 여러 위치에서 참조할 수 있다.
- 파일 공유가 가능하면서도 순환 구조로 인한 문제를 방지할 수 있다.

## 일반 그래프 디렉터리(General Graph Directory)
디렉터리 간의 연결에 순환까지 허용하는 구조이다.

- 파일 및 디렉터리 공유 측면에서 가장 유연하다.
- 디렉터리 트리를 순회하는 과정에서 무한 루프가 발생하지 않도록 순환 감지 및 회피가 필요하다.
