# 하드웨어적 해결 방법
피터슨이나 데커 알고리즘에서 필요한 검사와 변경 기능을 CPU의 명령어 수준에서 원자적으로 수행할 수 있도록 지원한다. 또는, 상호 배제가 필요한 코드 영역에서 인터럽트를 금지시키는 방법도 있다.

## 인터럽트 비활성화(Disabling Interrupts)
인터럽트 비활성화는 임계 영역에 진입할 때 인터럽트 기능을 끄고, 탈출할 때 다시 켜서 임계 영역의 코드가 실행되는 동안 인터럽트에 의한 컨텍스트 스위칭을 차단하는 방법이다.

하지만 현재 CPU에서만 인터럽트를 비활성화 하는 것이기 때문에, 멀티프로세서 환경에서는 다른 CPU의 실행을 막을 수 없어 올바르게 동작하지 않는다.

```c
void lock(struct lock *l) {
    cli(); // 인터럽트 비활성화
}

void unlock(struct lock *l) {
    sti(); // 인터럽트 활성화
}
```

## Test-and-Set(TAS)
TAS 연산은 하나의 변수(보통 락 변수)를 사용하여 구현된다. 이 변수는 잠김(`true`)과 해제(`false`) 상태를 가질 수 있다.

1. 현재 lock 상태를 저장한다.
2. lock을 true로 설정한다. (락을 사용하겠다고 표시)
3. 기존 lock 상태를 반환한다.

메모리 위치의 기존 값을 반환하고, 해당 위치의 값을 새로운 값으로 설정하는 동작이 원자적(atomic)으로 실행된다.

```c
boolean test_and_set (boolean *lock) {
    boolean old = *lock;
    *lock = true;
    return old;
}
```

```c
do {
    while (test_and_set(&lock));

    // 임계 영역

    lock = false;

    // 나머지 영역
} while (true);
```

## Compare-and-Swap(CAS)
CAS 연산은 다음 세개의 매개변수를 받는다.

- `value`: 변경할 대상 주소
- `expected`: 예상하는 기존 값
- `new_value`: 변경할 새로운 값

메모리 위치의 현재 값을 예상되는 값과 비교하고, 일치하는 경우에만 새로운 값으로 변경한다. 일치하지 않으면 아무 변경도 하지 않는다. 이 비교와 변경 동작이 원자적(atomic)으로 실행된다.

```c
int compare_and_swap (int *value, int expected, int new_value) {
    int old = *value;

    if (*value == expected)
        *value = new_value;

    return old;
}
```

```c
do {
    while (compare_and_swap(&lock, 0, 1) != 0);

    // 임계 영역

    lock = 0;

    // 나머지 영역

} while (true);
```
