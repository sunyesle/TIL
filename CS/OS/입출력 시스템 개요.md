# 입출력 시스템 개요

**입출력**(**I/O**) **시스템**은 CPU와 메모리, 주변 장치 간의 통신을 관리한다.

## 입출력 시스템의 목표

- **효율성**: 입출력 작업으로 인해 CPU가 낭비되는 시간을 최소화한다.
- **일반성**: 다양한 입출력 장치를 일관된 방식으로 처리한다.

## 기본 구성 요소

| 구성 요소 | 역할 |
|---|---|
| **입출력 장치** | 데이터 입력 및 출력을 담당하는 하드웨어 장치이다. |
| **장치 컨트롤러** | CPU와 입출력 장치 사이에서 명령과 데이터를 전달하고 장치를 제어하는 하드웨어이다. |
| **장치 드라이버** | 운영체제와 입출력 장치 사이의 인터페이스 역할을 하며, 장치 컨트롤러를 통해 장치를 제어하는 소프트웨어이다. |
| **버스** | CPU, 메모리, 입출력 장치 등의 구성 요소 사이에서 데이터와 제어 정보를 전송하는 하드웨어 구성 요소이다. |
| **입출력 소프트웨어** | 입출력 작업을 관리하고 조정하는 운영체제의 소프트웨어 구성 요소이다. |

운영체제는 각 입출력 장치의 구체적인 제어 방식을 장치 드라이버에 맡기고, 장치 드라이버를 통해 장치 컨트롤러를 제어한다.
이를 통해 서로 다른 입출력 장치를 일관된 방식으로 사용할 수 있다.
