# 프레임 할당

## 최소 프레임 수
하나의 명령어가 여러 페이지에 접근할 수 있으므로, 명령어를 정상적으로 실행하기 위해 필요한 최소한의 프레임은 확보해야 한다.
최소 프레임 수는 시스템 아키텍처에 따라 다르며, 단일 명령어가 접근할 수 있는 페이지 수의 최댓값을 기준으로 결정된다.

명령어에서 간접 주소 사용이 가능하다면, 여러 개의 프레임이 필요할 수 있다.
1. 명령어가 담긴 페이지
2. 명령어 상의 주소가 참조하는 페이지
3. 그 참조된 주소의 내용이 가리키는 페이지

## 프레임 할당 알고리즘
프로세스당 할당할 프레임 개수를 결정한다.

- **균등 할당\(Equal Allocation\)**: 모든 프로세스에게 동일한 개수의 프레임을 할당한다.
- **비례 할당\(Proportional Allocation\)**: 프로세스의 크기에 비례하여 프레임을 할당한다.
- **우선순위 할당\(Priority Allocation\)**: 프로세스의 우선순위에 따라 차등적으로 프레임을 할당한다.

## 전역 할당과 지역 할당
페이지 교체 시에 어떤 프로세스의 프레임을 교체 대상으로 삼을 것인가에 대한 정책이다.

- **전역 교체(Global Replacement)**
   - 모든 프로세스의 프레임 중에서 대체할 프레임을 선택한다.
   - 메모리 활용도가 높지만, 한 프로세스의 메모리 사용량이 다른 프로세스의 성능에 영향을 줄 수 있다.
- **지역 교체(Local Replacement)**
   - 자신에게 할당된 프레임 중에서만 대체할 프레임을 선택한다.
   - 프로세스 간 메모리 사용에 대한 간섭이 적지만, 다른 프로세스에 사용 가능한 프레임이 남아 있어도 활용할 수 없다.

## 비균등 메모리 접근 (Non-Uniform Memory Access, NUMA)
지금까지는 모든 메모리가 동일한 접근 시간을 가진다고 가정했지만, 다중 프로세서 시스템에서는 메모리에 따라 접근 시간이 달라질 수 있다.

NUMA 구조에서 프로세서는 자신의 로컬 메모리에 접근할 때가 원격 메모리에 접근할 때보다 더 빠르다.

운영체제는 메모리 접근 시간을 줄이기 위해 프로세스를 실행하는 프로세서의 로컬 메모리에 해당 프로세스가 필요한 메모리를 우선적으로 할당한다.
