# 대용량 저장장치 구조 개요
대용량 저장장치는 메인 메모리보다 훨씬 큰 용량을 제공하며, 전원이 꺼져도 데이터가 유지되는 **비휘발성 저장장치**(Non-Volatile Memory Devices, NVM)라는 특징이 있다.

## 하드 디스크 드라이브(Hard Disk Drive, HDD)
**HDD**는 **자기 디스크**에 데이터를 저장하는 저장장치이다.

자기 물질이 코팅된 원형 **플래터**(Platter)가 회전하며, 각 플래터의 표면에는 데이터를 읽고 쓰기 위한 **헤드**(Head)가 존재한다.

플래터의 표면은 여러 개의 동심원으로 나뉘며 이를 **트랙**(Track)이라고 한다. 트랙은 다시 여러 개의 섹터로 나뉜다. 같은 위치에 있는 트랙들을 묶은 것을 **실린더**(Cylinder)라고 한다.

운영체제는 일반적으로 디스크를 블록(Block)의 집합으로 바라본다. 특정 물리적 데이터 블록은 해당 블록이 위치한 헤드-섹터-실린더 번호를 통해 지정된다.

HDD는 데이터를 읽거나 쓰기 위해 물리적으로 헤드를 이동시키고 플래터를 회전시켜야 한다. 따라서 디스크 접근 시간은 크게 탐색 시간과 회전 지연의 영향을 받는다.

- **탐색 시간(Seek Time)**: 헤드가 원하는 트랙으로 이동하는 데 걸리는 시간
- **회전 지연(Rotational Latency)**: 원하는 섹터가 헤드 아래로 회전하여 오는 시간

## 솔리드 스테이트 드라이브(Solid-State Drive, SSD)
**SSD**는 **플래시 메모리**에 데이터를 저장하는 저장장치이다.

움직이는 부품이 없기 때문에 HDD에서 발생하는 탐색 시간이나 회전 지연이 없으며, 매우 빠른 접근 속도를 제공한다.

하지만, 플래시 메모리 셀의 쓰기 횟수 제한 때문에 수명이 제한적이다.
