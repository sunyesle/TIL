# 스왑 공간 관리
**스왑 공간**(Swap Space)은 가상 메모리 시스템에서 RAM 용량 제약을 보완하기 위해 보조 저장장치에 마련하는 공간이다.

RAM이 부족할 때, 사용되지 않는 메모리 페이지를 디스크로 옮겨(Swap Out) RAM 공간을 확보하고, 필요할 때 다시 RAM으로 불러와(Swap In) 사용한다.

## 스왑 공간 위치
스왑 공간은 디스크 저장 장치에 위치하며, 두 가지 주요 방식으로 할당된다.

| 방식 | 특징 | 장점 | 단점 |
|---|---|---|---|
| **스왑 파일**(Swap File) | 일반 파일 시스템 내의 파일이다. | 생성 및 크기 변경이 유연하다 | 파일 시스템의 오버헤드로 속도가 느리다. |
| **스왑 파티션**(Swap Partition) | 디스크의 별도 파티션이다. | 파일 시스템의 오버헤드가 없어 빠르고 효율적이다. | 크기 조절이 어렵고 디스크 공간이 미리 고정된다. |

## 스왑 공간 관리
스왑 공간은 페이징을 지원하기 위해 물리 메모리의 페이지와 대응되는 **슬롯**(Slot) 단위로 관리된다.

운영체제는 각 슬롯의 상태를 관리하기 위해 **스왑 맵**(Swap Map)을 사용한다. 0은 사용 가능한 슬롯을 나타내고, 1 이상은 해당 슬롯을 사용하는 페이지의 수를 나타낸다.
