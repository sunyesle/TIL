# RAID 구조
**RAID**(Redundant Array of Independent Disks)는 여러 개의 디스크를 묶어 신뢰성과 성능을 향상시키는 기술이다.

## 중복성을 통한 신뢰성 향상
### 미러링(Mirroring)
**미러링**은 같은 데이터를 여러 디스크에 동시에 저장하는 방식이다.
디스크 하나가 고장 나도 다른 디스크에 데이터가 존재하기 때문에 데이터를 보존할 수 있다.

### 패리티(Parity)
**패리티**는 XOR(배타적 논리합) 연산을 이용해 여러 데이터의 패리티 정보를 계산하여 별도로 저장하는 방식이다.
디스크 하나가 고장 나도 다른 디스크의 데이터와 패리티 정보를 이용해 손실된 데이터를 복구할 수 있다.

패리티 정보는 XOR의 다음 성질을 이용한다.
```txt
A XOR A = 0 // 자기 자신과 XOR하면 0
A XOR 0 = A // 0과 XOR하면 그대로
```

데이터 A, B, C를 저장한다면 패리티 정보 P는 다음과 같이 계산한다.
```txt
P = A XOR B XOR C
```

여러 데이터 중 하나가 손실되었을 때, 나머지 데이터와 패리티 정보를 XOR 하면 손실된 데이터를 계산할 수 있다.
예를 들어 B가 손실되었다면, A, C, P를 이용해 B를 복구할 수 있다.
```txt
A XOR C XOR P
= A XOR C XOR (A XOR B XOR C)
= (A XOR A) XOR B XOR (C XOR C)
= 0 XOR B XOR 0
= B
```

### 비교
|  | 미러링 | 패리티 |
|---|---|---|
| **방식** | 데이터 1:1 완전 복제 | XOR 연산을 통한 복구 값 저장 |
| **공간 효율성** | 낮음(50%) | 높음(디스크가 늘어날수록 효율 증가) |
| **쓰기 성능** |복제만 하면 되므로 비교적 높음 | 패리티 연산으로 인해 상대적으로 낮음 |

## 병렬 처리를 통한 성능 향상

### 스트라이핑(Striping)
**스트라이핑**은 하나의 데이터를 여러 디스크에 나누어 저장하여, 여러 디스크가 데이터를 병렬로 처리할 수 있도록 하는 방식이다.
데이터를 나누어 저장하는 단위에 따라 비트 레벨, 바이트 레벨, 블록 레벨 스트라이핑으로 구분할 수 있다.
