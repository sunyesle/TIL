# 중앙 처리 장치(CPU)
CPU는 컴퓨터에서 기억, 해석, 연산, 제어라는 4가지의 주요 기능을 담당하는 장치다. 프로그램의 명령어를 해석하여 데이터를 연산 및 처리함으로써 컴퓨터의 각 장치들을 제어한다.

CPU는 크게 **산술 논리 장치**, **제어장치**, **레지스터** 3가지로 구성되어 있다.

## 산술 논리 장치(Arithmetic and Logical Unit, ALU)
산술논리장치는 덧셈과 뺄셈 같은 **산술 연산**과 논리합, 논리곱, 배타적 논리합과 같은 **논리 연산**을 계산하는 디지털 회로다.

![산술논리장치](https://github.com/user-attachments/assets/c49c6bfd-4ae9-46d1-bec5-8722d9dccfcf)

산술논리장치는 연산기와 논리회로 등으로 구성되며, 제어장치로부터 전달받은 제어신호에 따라 연산을 수행한다. 연산 결과는 레지스터에 저장되며 이때 발생한 부가 정보는 상태 레지스터에 저장된다.

**상태 레지스터 플래그**<br>
- `S, sign flag 부호 플래그`: 연산 결과가 음수일 경우 참이 된다.
- `Z, zero flag 제로 플래그`: 연산 결과가 0일 경우 참이 된다.
- `C, carry flag 캐리 플래그`: 연산 결과가 올림수나 빌림수가 발생하였을 경우 참이 된다.
- `O, overflow flag 오버플로우 플래그`: 부호 있는 숫자의 연산 결과가 비트 범위를 넘어섰을 때 참이 된다.
- `P, parity flag 패리티 플래그`: 연산 결과에서 1로 된 비트의 수가 짝수일 경우 참이 된다.
- `I, interrupt flag 인터럽트 플래그`: 인터럽트 가능 여부를 나타낸다. 가능할 때 참이 된다.
- `S, supervisor flag 슈퍼바이저 플래그`: 커널 모드로 실행 중인지, 사용자 모드로 실행 중인지를 나타낸다. 커널 모드일 경우 1, 사용자 모드일 경우 0이 된다.

상태 플래그 종류와 구성은 CPU 아키텍처마다 다를 수 있다.

## 제어 장치(Control Unit, CU)
제어장치는 명령어를 해석하고 데이터의 처리 순서를 결정하며, CPU 내부와 외부 장치에 제어신호를 보내는 역할을 한다.

![제어장치](https://github.com/user-attachments/assets/34a68cf7-f2e0-490b-ba4c-a941d4477a1c)

제어장치는 클럭, 명령어, 상태 플래그, 제어신호 등을 입력받아, ALU, 레지스터, 시스템 버스에 적절한 제어신호를 전달한다.

**클럭**(clock)은 CPU의 모든 동작을 동기화하는 기준 신호이며, 일정한 주기로 1과 0이 반복된다.
이 반복 단위를 주기(period)라고 하며, 1초 동안의 반복 횟수를 주파수(frequncy, Hz)라고한다.
예를 들어 2.4GHz는 1초에 2.4 × 10^9번의 클럭 사이클이 발생함을 의미한다. 오버클럭을 하게 되면 주파수가 증가하여 CPU의 처리 속도를 증가시킬 수 있다.

![클럭](https://github.com/user-attachments/assets/b557db09-9aae-4396-977f-18e267795e1a)

## 레지스터(Register)
레지스터는 CPU 내부의 고속 임시 저장장치이다. 프로그램 속의 명령어와 데이터는 프로그램 실행 전/후로 레지스터에 저장된다. CPU 내부에는 다양한 레지스터가 존재하며, 각기 다른 역할을 수행한다.

- **프로그램 카운터\(Program Counter, PC\)**: 다음에 실행할 명령어의 주소를 저장한다.
- **명령어 레지스터\(Instruction Register, IR\)**: 현재 실행 중인 명령어를 저장한다.
- **메모리 주소 레지스터\(Memory Address Register, MAR\)**: 접근할 메모리 주소를 저장한다.
- **메모리 버퍼 레지스터\(Memory Buffer Register, MBR\)**: 메모리와 주고받을 데이터를 저장한다.
- **누산기\(Accumulator\)**: 연산의 중간 결과 및 최종 결과를 저장한다.
- **상태 레지스터\(Status Register, SR\)**: 연산 결과의 상태 정보를 저장한다.
- **베이스 레지스터\(Base Register, BR\)**: 기준 주소를 저장한다.
- **인덱스 레지스터\(Index Register\)**: 베이스 레지스터를 기준으로 한 상대 주소를 저장한다.
- **범용 레지스터\(General Register, GR\)**: 연산에 사용되는 데이터나 주소를 임시로 저장하는 데 사용된다.
- **스택 포인터\(Stack Pointer, SP\)**: 스택의 최상위 주소를 가리킨다.

# 캐시 메모리
캐시 메모리는 CPU와 주기억장치 사이에 위치하며, CPU의 연산 속도와 주기억장치 접근 속도의 차이로 인한 병목 현상을 줄이기 위해 사용한다.

캐시 메모리는 SRAM(Static RAM)을 사용하여 만든다. 전원이 켜져 있는 동안 재충전(Refresh) 없이 데이터를 유지하며,
일반적인 주기억장치에 사용되는 DRAM보다 속도가 빠르다.

캐시 메모리는 CPU 코어와의 거리에 따라 L1, L2, L3 계층으로 구성된다.
일반적으로 L1과 L2 캐시는 각 코어가 독립적으로 가지고 있으며, L3 캐시는 여러 코어가 공유한다.
멀티코어 프로세서에서는 각 코어가 독립적인 L1, L2 캐시를 가지므로 데이터 일관성을 유지하기 위한 캐시 동기화가 중요하다.

캐시 메모리는 CPU가 사용할 가능성이 높은 데이터를 미리 저장하며, *참조 지역성의 원리*에 따라 메모리에서 가져올 데이터를 결정한다.

> **참조 지역성의 원리**
>
> - **시간 지역성**(temporal locality): CPU는 최근에 접근했던 메모리 공간에 다시 접근하려는 경향이 있다.
> - **공간 지역성**(spatial locality): CPU는 접근한 메모리 공간 근처에 접근하려는 경향이 있다.

# 주기억장치(Main Memory)
주기억장치는 실행 중인 프로그램의 명령어와 데이터를 저장하기 위해 사용된다.

주기억장치는 DRAM(Dynamic RAM)을 사용하여 만든다. 전원이 켜져 있는 동안에도 시간이 지나면 데이터가 사라지기 때문에 주기적인 재충전(refresh)이 필요하며,
캐시 메모리에 사용되는 SRAM보다 속도는 느리지만 대용량으로 구성하기에 유리하다.

# 보조기억장치
보조기억장치는 대용량의 비휘발성 데이터를 영구적으로 저장하기 위해 사용된다.

보조기억장치에는 하드디스크와 플래시 메모리가 있다.
하드디스크(HDD)는 자기적인 방식으로 데이터를 저장하는 장치이며, 플래시 메모리(SSD)는 전기적으로 데이터를 읽고 쓰는 반도체 기반의 저장장치이다.

# 시스템 버스(system bus)
시스템 버스는 CPU, 메모리, 입출력 장치 간의 데이터 전달을 위한 통신 경로이다.

시스템 버스는 다음 세 가지로 구성된다.
- **주소 버스**(address bus), **데이터 버스**(data bus), **제어 버스**(control bus)로 구성된다.
- **주소 버스**(Address Bus): CPU가 접근할 메모리나 장치의 주소를 전달한다.
- **데이터 버스**(Data Bus): CPU와 메모리, 입출력 장치 간에 실제 데이터를 전달한다.
- **제어 버스**(Control Bus): 읽기/쓰기 신호, 인터럽트 요청 등 각 장치의 동작을 제어하는 신호를 전달한다.

# 입출력 장치
입출력 장치는 컴퓨터 외부에 연결되어 컴퓨터 내부와 정보를 교환할 수 있는 장치이다.
대표적인 입출력 장치로 키보드, 모니터, 마우스 등이 있다.

입력장치는 컴퓨터가 인식할 수 있는 형태로 변환시켜 메모리로 읽어 들이는 장치이고,
출력장치는 컴퓨터에서 처리된 내용을 사용자가 인식할 수 있는 형태로 바꾸어 표시하는 장치이다.
