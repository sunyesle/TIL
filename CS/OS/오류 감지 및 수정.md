# 오류 감지 및 수정
**오류 제어**는 데이터 전송 및 저장 과정에서 발생하는 비트 오류를 감지하고 수정하여 데이터의 무결성(Integrity)을 보장하는 기술이다.
## 오류 감지 기법
데이터에 추가적인 여분 비트를 붙여 오류 발생 여부를 판단한다.

### 패리티 검사(Parity Check)
데이터에 1비트를 추가하여 전체 비트에서 1의 개수가 짝수 또는 홀수가 되도록 하는 방식이다.
데이터에 1의 개수가 짝수가 되도록 할지, 홀수가 되도록 할지에 따라 패리티 비트를 0 또는 1로 정한다.

짝수 개의 비트가 뒤집히는 오류는 감지하지 못한다는 한계가 있다.

### 체크섬(Checksum)
데이터를 일정한 단위(예: 16비트)로 나눈 후, 모든 블록의 값을 단순 합산하여 검사용 값을 만드는 방식이다.

송신 측에서는 모든 데이터 블록을 더한 후, 그 결과의 1의 보수를 체크섬으로 데이터와 함께 전송한다. 수신 측에서는 데이터와 체크섬을 함께 더한 후, 그 결과의 모든 비트가 1인지 확인한다.

### 순환 중복 검사(Cyclic Redundancy Check, CRC)
데이터를 생성 다항식으로 나눈 나머지 값을 이용하는 방식이다.

송신 측은 데이터를 생성 다항식으로 나누며, 여기서 나온 나머지를 데이터와 함께 전송한다. 수신 측에서도 같은 값으로 나누어 나머지가 0인지 확인한다.

## 오류 수정 기법
오류가 발생한 데이터를 원래의 데이터로 복구하는 기법이다.

오류 수정 방법은 크게 **전진 오류 수정**과 **후진 오류 수정**으로 나눌 수 있다.

### 전진 오류 수정(Forward Error Correction, FEC)
송신 측에서 오류 수정에 필요한 추가 정보를 데이터와 함께 전송하고, 수신 측에서 이를 이용하여 오류를 직접 수정하는 방식이다.

수신 측에서 별도의 재전송을 요청하지 않고도 오류를 수정할 수 있기 때문에 재전송이 어렵거나 지연을 줄여야 하는 환경에서 사용된다.

### 후진 오류 수정(Backward Error Correction, BEC)
수신 측에서 데이터의 오류를 감지한 후, 송신 측에 데이터의 재전송을 요청하여 오류를 수정하는 방식이다.

수신 측은 오류 감지 기법을 이용하여 오류 여부를 확인한다.
오류가 발견되면 송신 측에 재전송을 요청하고, 송신 측은 해당 데이터를 다시 전송한다.
