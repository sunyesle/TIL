# 세그멘테이션(Segmentation)
**세그멘테이션**은 프로세스를 코드, 데이터, 스택 등의 의미 있는 단위인 세그먼트로 나누어 메모리에 불연속적으로 할당하는 메모리 관리 기법이다.

코드, 데이터, 스택 등의 의미 있는 단위들로 **세그먼트**를 정의한다. 세그먼트의 크기는 균일하지 않다.

세그먼트의 크기에 맞춰 메모리를 할당하며, 매핑 정보는 **세그먼트 테이블**로 관리된다.

할당 크기가 가변적이기 때문에 내부 단편화가 거의 발생하지 않는다. 하지만 세그먼트가 해제되면서 가용 공간이 여러 곳으로 흩어지면 외부 단편화가 발생할 수 있다.

## 세그먼트 테이블(Segment Table)

<img width="666" height="474" alt="8_08_SegmentationHardware" src="https://github.com/user-attachments/assets/5e01f630-3825-4abc-aa70-e385a006d095" />

- **s**: 세그먼트 번호(segment number)
- **d**: 세그먼트 오프셋(segment offset)
- **base**: 세그먼트의 시작 물리 주소
- **limit**: 세그먼트의 크기

> **물리 주소 = base + 세그먼트 오프셋**

### 주소 변환 과정
1. 논리 주소에서 세그먼트 번호와 세그먼트 오프셋을 추출한다.
2. 세그먼트 테이블에서 세그먼트 번호를 이용해 해당 세그먼트의 base와 limit을 확인한다.
3. 세그먼트 오프셋이 limit을 초과하지 않는지 확인한다.
4. base에 세그먼트 오프셋을 더해서 최종 물리 주소를 구한다.
