# 메모리 관리
프로세스가 실행되기 위해서는 프로그램과 데이터를 메모리에 적재해야 한다.
메모리 관리는 여러 프로세스가 메모리를 효율적이고 안전하게 사용할 수 있도록 관리하는 운영체제의 기능이다.

## 메모리 관리의 목표
메모리 관리는 다음과 같은 목표를 가진다.

- **효율성**: 제한된 메모리 공간을 효율적으로 사용하여 메모리 낭비를 최소화한다.
- **성능**: 메모리 접근 시간을 줄이고 CPU가 메모리를 효율적으로 사용할 수 있도록 한다.
- **보호**: 프로세스가 다른 프로세스나 운영체제의 메모리 영역에 임의로 접근하지 못하도록 보호한다.

## 메모리 관리의 기능
메모리 관리는 다음과 같은 기능을 포함한다.

- **메모리 할당**: 프로세스가 실행될 때 필요한 메모리 공간을 할당한다.
- **주소 변환**: 프로그램이 사용하는 논리적 주소를 물리적 주소로 변환한다.
- **메모리 보호**: 프로세스가 다른 프로세스나 운영체제의 메모리 영역에 무단으로 접근하지 못하도록 보호한다.
- **메모리 공유**: 필요한 경우 여러 프로세스가 메모리 영역을 공유할 수 있도록 지원한다.
- **메모리 회수**: 프로세스가 종료되면 사용하던 메모리 공간을 회수하여 다른 프로세스가 사용할 수 있도록 한다.
