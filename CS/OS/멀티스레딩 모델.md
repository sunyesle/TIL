# 멀티스레딩 모델
최신 시스템에서 관리되는 스레드는 사용자 스레드와 커널 스레드로 나뉜다.

**사용자 스레드**는 사용자 수준의 스레드 라이브러리에서 관리된다. 응용 프로그램 프로그래머가 생성하고 제어한다.<br>
**커널 스레드**는 운영체제 커널에 의해 직접 생성되고 관리된다. 이를 통해 여러 작업이나 시스템 호출을 동시에 처리할 수 있도록 한다.

사용자 스레드를 커널 스레드에 매핑하는 방식에는 여러 가지 모델이 존재한다.
## 다대일 모델(M:1)
여러 사용자 수준 스레드가 모두 하나의 커널 스레드에 매핑된다.

스레드 관리는 사용자 수준의 스레드 라이브러리에서 처리되므로 매우 효율적이다.

하지만 하나의 스레드가 차단 시스템 호출을 수행하면 전체 프로세스가 차단되며, 하나의 커널 스레드만 사용하므로 멀티코어 환경에서 병렬 실행이 불가능하다.

## 일대일 모델(1:1)
각 사용자 수준 스레드가 하나의 커널 스레드에 매핑된다.

차단 시스템 호출이 발생해도 다른 스레드는 계속 실행될 수 있으며, 멀티코어 환경에서 병렬 실행이 가능하다.

하지만 커널 스레드 생성 및 관리 비용으로 인해 오버헤드가 증가하며, 생성 가능한 스레드 수에 제한이 존재한다.

<img width="494" height="187" alt="4_06_OneToOne" src="https://github.com/user-attachments/assets/43c399a9-4c05-41be-9198-0b3415c9f660" />

## 다대다 모델(M:N)
여러 사용자 스레드를 그보다 같거나 작은 수의 커널 스레드에 매핑하는 방식이다.

일대일 모델과 다대일 모델의 장점을 결합하였다.
차단 시스템 호출이 발생해도 다른 스레드는 계속 실행될 수 있으며, 멀티코어 환경에서 병렬 실행이 가능하다.
또한, 여러 사용자 스레드를 소수의 커널 스레드 위에서 움직여 자원 효율성을 높인다.

## 2계층 모델
다대다 모델의 변형으로, 일부 사용자 스레드를 특정 커널 스레드에 1:1로 매핑할 수 있는 모델이다.

기본적으로 M:N 구조를 유지하면서 필요에 따라 일부 스레드에 대해 1:1 매핑을 제공한다.
