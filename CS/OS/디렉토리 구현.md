# 디렉토리 구현
디렉터리는 파일 이름과 해당 파일을 식별할 수 있는 정보를 연결하여 관리한다.

## 선형 리스트
디렉터리의 파일 정보를 순차적인 목록 형태로 저장한다.

파일 탐색 시 앞에서부터 파일 이름을 차례대로 비교하기 때문에 평균 검색 시간은 **O(n)**​이다.
새 파일을 생성할 때는 동일한 이름의 파일이 존재하는지 확인하기 위해 전체 항목을 검색해야 한다.

구현이 단순하지만, 파일 수가 많아질수록 탐색 시간이 증가한다.

## 해시 테이블
파일 이름을 해시 함수에 입력하여 계산된 값을 이용해 저장 위치를 결정한다.

해시 값을 이용해 해당 위치에 직접 접근하므로 평균 검색 시간은 **O(1)**에 가깝다.

서로 다른 파일 이름이 동일한 해시 값을 가지는 충돌(Collision)​이 발생할 수 있으며, 이를 처리하기 위한 추가적인 방법(연결 리스트 등)이 필요하다.

선형 리스트에 비해 빠른 탐색이 가능하지만, 해시 테이블을 관리하기 위한 추가 공간과 충돌 처리 등의 복잡성이 발생한다.
