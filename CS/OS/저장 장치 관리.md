# 저장 장치 관리
## 드라이브 포매팅
디스크를 사용하기 위해서는 디스크의 물리적 구조를 구성하고, 파티션과 볼륨 및 파일 시스템을 설정하는 과정이 필요하다.

### 물리적 구조 구성
저장장치가 데이터를 저장하기 전에 컨트롤러가 읽고 쓸 수 있도록 섹터나 페이지 등의 저장 영역을 구성해야 한다. 이를 **저수준 포매팅**이라고 한다.

이 과정에서 디스크를 여러 개의 섹터로 구성하고, 각 섹터를 구분할 수 있도록 필요한 정보를 기록한다.

각 섹터에 쓰이는 자료구조는 보통 헤더(Header), 자료 구역(Data Area), 트레일러(Trailer)로 구성되며, 
헤더와 트레일러에는 섹터 번호, 오류 수정 코드(Error-Correcting Code, ECC) 등 컨트롤러가 사용하는 정보가 포함된다.

대부분의 하드디스크가 제조 과정에서 이 절차를 거친다.

### OS가 사용할 저장 공간 구성
#### 1. 파티션(Partition)
물리적 디스크를 논리적 단위인 **파티션**으로 나눈다.

각 파티션에는 별도의 OS를 설치하거나 파일 시스템을 구성할 수 있다.

#### 2. 볼륨(Volume)
파티션이나 물리적 디스크를 논리적 저장 공간 단위인 **볼륨**으로 구성한다.

파티션은 디스크를 논리적으로 나눈 영역인 반면, 볼륨은 운영체제에서 하나의 논리적 저장 공간으로 사용할 수 있도록 구성한 단위이다. 볼륨은 단일 파티션으로 구성할 수도 있고, 여러 파티션이나 물리적 디스크를 묶어서 구성할 수도 있다. (예: RAID)

#### 3. 논리적 포매팅(Logical Formatting)
**논리적 포매팅**은 장치에 파일 시스템 구조를 초기화하여 파일과 디렉터리를 저장하고 관리할 수 있는 초기 환경을 구축하는 과정이다.

### 요약
- **저수준 포매팅**: 저장장치 자체의 물리적 저장 구조를 구성
- **파티션**: 저장장치를 논리적인 영역으로 구분
- **볼륨**: 운영체제에서 사용할 논리적인 저장 단위를 구성
- **논리적 포맷팅**: 저장 단위에 파일 시스템을 생성

## 부트 블록(Boot Block)
컴퓨터를 부팅하려면 운영체제를 찾아 실행하는 **부트스트랩 프로그램**(Bootstrap Program)이 먼저 실행되어야 한다. 부트스트랩 프로그램은 저장장치의 고정된 위치에 저장되며, 이 영역을 **부트 블록**이라고 한다.

컴퓨터의 전원이 켜지면 펌웨어(ROM)에 저장된 작은 부트스트랩 로더가 먼저 실행되고, 저장장치의 부트 블록에서 더 완전한 부트스트랩 프로그램을 가져와 메모리에 적재한다. 이후 부트스트랩 프로그램이 운영체제 커널을 메모리에 적재하고 실행하면서 운영체제의 부팅이 시작된다.

## 손상된 블록(Bad Block)
디스크 컨트롤러는 데이터를 읽거나 쓸 때 ECC를 이용하여 오류를 검사한다.

ECC를 통해 데이터를 복구할 수 있다면 이를 **소프트 오류**(Soft Error)라고 하며, 손상된 섹터를 ​예비 섹터(Spare Sector)로  대체하는 **​섹터 포워딩**(Sector Forwarding, Sector Sparing)을 수행하여 이후 해당 섹터를 사용하지 않도록 한다.

ECC를 통해 데이터를 복구할 수 없는 경우에는 **하드 오류**(Hard Error)가 발생한 것으로, 백업에서 데이터를 복구하거나 파일을 다시 생성해야 한다.
