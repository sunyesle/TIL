# 커널 메모리의 할당

## 버디 시스템(Buddy System)
**버디 시스템**은 물리 메모리를 2의 거듭제곱 크기의 블록으로 나누어 관리하는 메모리 할당 방식이다.

메모리가 항상 2의 거듭제곱으로 할당되며, 요청한 크기가 2의 거듭제곱이 아닌 경우 가장 가까운 큰 크기로 올림하여 할당한다.

### 동작 원리
- **분할(Split)**: 만약 적절한 크기의 블록이 없다면, 다음으로 큰 블록을 반으로 나누어 버디(쌍둥이) 블록을 만든다.
- **병합(Coalescing)**: 블록 해제 시, 인접한 비어 있는 버디 블록을 찾아 합쳐서 더 큰 블록으로 재귀적으로 병합한다.

### 장단점
- **장점**
   - 인접 버디 블록의 주소 계산이 쉬워 단편화된 메모리를 빠르게 병합할 수 있다. 블록 시작 주소와 블록 크기를 배타적 논리합(XOR)으로 연산하면 동일한 크기의 버디 블록 주소가 나온다.
- **단점**
   - 요청 메모리 크기가 2의 거듭제곱이 아닌 경우 내부 단편화가 발생한다.

## 슬랩 할당(Slab Allocator)
슬랩 할당은 버디 시스템 위에서 동작하며, 커널에서 자주 생성되고 해제되는 작은 크기의 객체를 효율적으로 관리하는 메모리 할당 기법이다.

**슬랩**(Slab)은 하나 이상의 연속된 페이지로 구성된다. **캐시**(Cache)는 하나 이상의 슬랩으로 구성된다.

<img width="633" height="461" alt="Slab Allocator" src="https://github.com/user-attachments/assets/81bba89c-fc21-4c38-9951-df6278616e74" />

### 동작 원리
- 커널 자료구조의 유형별로 캐시가 생성된다.
- 버디 시스템으로부터 메모리 블록을 할당받은 뒤, 이를 객체 크기에 맞춰 여러 개의 객체 공간으로 나누어 관리한다.
- 객체가 요청되면 해당 캐시에서 비어 있는 객체 공간을 찾아 할당한다.
- 객체가 해제되면 해당 공간을 다시 사용할 수 있도록 반환한다.

### 장단점
- **장점**
   - 객체 크기에 맞춰 할당되므로 내부 단편화가 최소화된다.
   - 매번 메모리를 새로 할당하고 해제하는 오버헤드를 없앨 수 있다.
