# 스토리지 스냅샷 CoW와 RoW
**스토리지 스냅샷**은 특정 시점의 데이터 상태를 보존하여, 이후 데이터가 변경되더라도 스냅샷 생성 시점의 상태를 확인하거나 복원할 수 있도록 하는 기능이다.

스냅샷은 데이터 블록을 가리키는 포인터 등의 참조 정보를 통해 특정 시점의 데이터 상태를 보존한다.

## Cow(Copy-on-Write)
스냅샷을 생성할때는 원본에 대한 포인터만 지정한다.
물리적인 데이터 복사가 이루어지지 않기 때문에 스냅샷을 빠르게 생성할 수 있다.

스냅샷이 참조하는 데이터가 변경되면 기존 데이터를 별도 공간에 복사하여 보존한 후 변경 작업을 수행한다.

이 과정에서 기존 데이터 읽기와 복사본 쓰기, 변경된 데이터 쓰기가 발생할 수 있어 추가적인 I/O 비용이 발생한다.

## RoW(Redirect-on-Write)
스냅샷을 생성할때는 CoW와 동일하게 원본에 대한 포인터만 지정한다.

스냅샷이 참조하는 데이터가 변경되면 기존 데이터를 덮어쓰지 않고, 변경된 데이터를 새로운 위치에 기록한다.
이후 메타데이터의 포인터를 새 데이터 블록으로 갱신한다.

기존 데이터가 유지되므로 스냅샷은 변경 전 데이터에 계속 접근할 수 있으며, 기존 데이터를 보존하기 위한 별도의 복사 작업을 줄일 수 있다.

## 비교
| 구분 | CoW | RoW |
|---|---|---|
| **데이터 변경** | 기존 데이터를 먼저 보존한 후 변경 | 새 위치에 데이터를 기록 |
| **기존 데이터 복사** | 변경 전 데이터 복사가 발생할 수 있음 | 기존 데이터 복사 없이 새 위치에 기록 |
| **쓰기 성능** | 기존 데이터 보존을 위한 추가 I/O 발생 가능 | 기존 데이터 복사 비용을 줄일 수 있음 |
| **스냅샷 생성** | 기존 데이터에 대한 참조를 활용해 빠르게 생성 가능 | 기존 데이터에 대한 참조를 활용해 빠르게 생성 가능 |
| **공간 사용** | 변경 전 데이터를 보존할 공간 필요 | 변경된 데이터와 새 메타데이터를 저장할 공간 필요 |
| **주요 고려 사항** | 변경 시 복사 비용 | 메타데이터 갱신 및 새 위치 할당 비용 |
