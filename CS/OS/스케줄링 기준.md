# 스케줄링 기준
## 주요 스케줄링 기준
스케줄링의 성능은 특정한 기준(Criteria)에 따라 평가된다.

- **CPU 이용률**: CPU가 작업을 수행하고 있는 시간의 비율
- **처리량**: 단위 시간당 완료된 프로세스의 개수
- **처리 시간**: 프로세스가 제출된 시점부터 완료될 때까지 걸린 전체 시간
- **대기 시간**: 프로세스가 준비 큐에서 CPU 할당을 받기 위해 대기한 시간의 총합
- **응답 시간**: 프로세스가 제출된 시점부터 최초의 응답이 생성될 때까지 걸린 시간

## 스케줄링 알고리즘의 목표
스케줄링은 크게 시스템 성능 향상과 사용자 경험 개선이라는 두 가지 목표를 가진다.

- **시스템 성능 향상**: CPU 이용률, 처리량 최대화
- **사용자 경험 개선**: 응답 시간, 대기 시간 최소화

일반적으로 스케줄링 알고리즘은 여러 스케줄링 기준의 평균값을 최적화하는 것을 목표로 한다.
하지만 스케줄링 기준은 서로 충돌하는 관계(Trade-off)에 있기 때문에 모든 기준을 동시에 만족시키기는 어렵다.
따라서 운영체제는 시스템 목적에 따라 여러 목표 사이에서 적절한 균형점을 선택한다.
