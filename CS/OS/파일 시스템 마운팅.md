# 파일 시스템 마운팅

**파일 시스템 마운팅**(Mounting)은 저장 장치나 파티션 등에 존재하는 파일 시스템을 기존 디렉터리 트리에 연결하여 접근할 수 있도록 하는 과정이다.
운영체제는 여러 파일 시스템을 하나의 디렉터리 트리로 통합하여 관리할 수 있으며, 사용자는 마운트된 파일 시스템을 기존 디렉터리 경로를 통해 접근할 수 있다.

**마운트 포인트**(Mount Point)는 새로운 파일 시스템이 연결되는 기존 디렉터리 트리의 위치를 의미한다.

**언마운트**(Unmount)는 연결된 파일 시스템을 디렉터리 트리에서 분리하는 과정이다. 일반적으로 저장 장치를 제거하기 전에 수행해야 하며, 데이터 무결성을 위해 버퍼의 데이터 쓰기(Flush) 작업을 완료한 후 파일 시스템을 분리한다.

## 마운팅 과정

1. **장치 인식**: 대상 장치와 파일 시스템 유형을 확인한다.
2. **연결**: 해당 파일 시스템의 최상위 디렉터리를 기존 디렉터리의 마운트 포인트에 연결한다.
3. **테이블 갱신**: 운영체제의 마운트 테이블에 장치와 마운트 포인트 정보를 기록한다.

## 자동 마운팅(Automatic Mounting)
**자동 마운팅**은 시스템이 부팅 시 운영체제가 파일 시스템을 자동으로 마운트하는 기능이다.

리눅스는 `/etc/fstab` 파일에 파일 시스템의 장치 또는 UUID, 마운트 포인트, 파일 시스템 유형, 마운트 옵션 등을 설정하면 시스템이 부팅될 때 해당 설정을 바탕으로 파일 시스템을 마운트한다.
