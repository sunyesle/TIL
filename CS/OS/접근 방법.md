# 접근 방법
## 순차 접근(Sequential Access)
파일의 레코드를 처음부터 끝까지 순서대로 읽거나 쓰는 방식이다.

- **원리**: 현재 파일 위치(CP, Current Position)를 유지하며, `read` 또는 `write` 연산 후 다음 위치로 이동한다.
- **주요 연산**: `read next`, `write next`, `reset`
- **활용**: 컴파일러 출력 파일이나 일반 문서 파일처럼 데이터를 순서대로 처리하는 경우에 사용된다.

## 직접 접근(Direct Access)
상대 블록 번호를 사용하여 파일 내의 어느 위치든 임의로 접근할 수 있는 방식이다.

- **원리**: 파일의 시작 위치를 기준으로 한 **상대 블록 번호**를 지정하여 원하는 블록에 접근한다.
- **주요 연산**: `read n`, `write n`, `position n`
- **활용**: 데이터베이스처럼 특정 데이터에 임의로 접근해야 하는 경우에 유용하다.

## 색인 접근(Indexed Access)
색인(Index)을 이용하여 원하는 데이터의 위치를 빠르게 찾을 수 있도록 하는 방식이다.

- **원리**: 별도의 **색인 테이블**(Index Table)에 데이터의 위치 정보를 저장하고, 색인을 이용하여 원하는 데이터에 접근한다.
- **활용**: 대용량 파일에서 특정 레코드나 데이터에 빠르게 접근할 때 유용하다.
