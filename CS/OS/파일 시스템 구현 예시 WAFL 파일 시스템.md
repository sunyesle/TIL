# 파일 시스템 구현 예시 WAFL 파일 시스템
**WAFL**(Write Anywhere File Layout)은 NetApp의 스토리지 시스템을 위해 개발된 파일 시스템이다.
기존 데이터 블록을 덮어쓰지 않고 새로운 위치에 기록하는 방식을 통해 스냅샷 지원과 쓰기 성능 최적화를 제공한다.

## 동작 방식
1. 파일의 데이터가 변경되면 기존 데이터 블록을 덮어쓰는 대신 새로운 위치에 기록한다.
2. 변경된 데이터를 가리키도록 관련 메타데이터를 갱신한다.
3. 변경 사항을 반영한 뒤, 더 이상 참조되지 않는 기존 블록은 나중에 재사용할 수 있다.

## 특징
- **쓰기 위치 제약이 적음**: 기존 데이터를 덮어쓰는 대신 다른 위치에 변경 데이터를 기록할 수 있다.
- **Redirect-on-Write 방식**: 기존 데이터 블록을 유지하면서 변경된 데이터를 새 위치에 기록하고, 관련 메타데이터를 갱신한다.
- **쓰기 성능 최적화**: 여러 쓰기 요청을 모아 디스크에 순차적으로 기록함으로써 랜덤 쓰기로 인한 디스크 I/O 비용을 줄인다.
- **스냅샷 지원**: 기존 데이터 블록을 보존하는 방식으로 특정 시점의 데이터 상태를 유지할 수 있다.
- **스토리지 관리**: 여러 디스크를 묶은 저장 공간에서 데이터를 관리하며, NetApp의 FlexVol 같은 논리적 볼륨을 지원한다.
