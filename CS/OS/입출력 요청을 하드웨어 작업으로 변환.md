# 입출력 요청을 하드웨어 작업으로 변환

사용자 프로그램이 파일 읽기 같은 추상적인 I/O를 요청하면, 운영체제는 이를 해당 장치에 맞는 장치 드라이버를 통해 하드웨어가 이해할 수 있는 구체적인 장치 컨트롤러 명령(하드웨어 연산)으로 변환하여 실행시킨다.

- **추상화 및 단순화**: 사용자 프로그램과 커널은 장치 구체적인 제어 방법을 알 필요 없이 통일된 I/O 인터페이스를 사용한다.
- **이식성**(Portability): 새로운 하드웨어가 추가되어도 장치 드라이버만 추가하면 되므로 시스템 수정이 최소화된다.
- **보안 및 안정성**: 사용자 프로그램이 하드웨어에 직접 접근하지 못하도록 하고, 커널이 I/O 요청과 장치 접근을 관리하여 시스템 자원을 보호한다.


## 입출력 요청의 계층적 변환 단계

### 사용자 프로그램
사용자 프로그램은 `print()`와 같은 라이브러리 함수나 시스템콜을 통해 I/O 작업을 요청한다.

### 커널 입출력 서브 시스템
시스템콜을 통해 커널 모드로 전환된 운영체제 커널은 I/O 요청을 처리하고 해당 장치에 맞는 장치 드라이버로 전달한다.

I/O 요청의 유효성 검사, I/O 스케줄링, 버퍼링, 캐싱 등 성능 최적화 작업을 수행한다.

### 장치 드라이버
운영체제와 특정 하드웨어 사이의 인터페이스이다.

운영체제 커널의 범용적인 I/O 요청을 해당 장치가 수행할 수 있는 구체적인 명령으로 변환하고, 장치 컨트롤러의 레지스터에 필요한 값을 기록하여 장치의 동작을 설정한다.

### 하드웨어 장치 컨트롤러
장치를 제어하는 하드웨어 구성 요소이다.

장치 드라이버가 레지스터에 설정한 값을 바탕으로 장치의 동작을 제어하고 실제 입출력 작업을 수행한다.
I/O 작업이 완료되면 CPU에 인터럽트를 발생시켜 작업 완료를 알린다.
